Connection details

Turn on the public gallery

Offline saving works without an account or backend. Public uploads need one shared Supabase project for this site.

  1. Create a project at supabase.com.
  2. Run supabase-setup.sql from the download in its SQL Editor.
  3. Set your GitHub Pages URL as the Auth Site URL. Use email/password sign-in; see SETUP.md for email delivery setup.
  4. Put your project URL and publishable key in config.js. Never use a secret or service_role key.
  5. Upload the updated config.js with the other app files. All visitors then share the same gallery.

There is no build command. The included SETUP.md explains each step and offline limits.

Your pocket-sized workspace

New: Publish HTMLs to the Public gallery, or Save offline to pin a frozen version. Offline copies never update automatically. Open Offline to check that the app itself is ready for offline use.

  1. Import HTML files or create a new one. Edit the source and press Run to execute HTML, CSS, and JavaScript in the embedded preview.
  2. Download exports your edited file. Your workspace saves automatically in this browser, not in your GitHub repository.
  3. Share pairs two devices using a code. Enable sharing on both, enter one device’s code on the other, and accept the request.

Supported previews: HTML, images, video, audio, PDFs (browser support varies), and text/code. Other files can be stored, downloaded, or transferred. Python, EXE, server code, and ZIP projects do not execute here.

HTML projects: self-contained HTML works best. Import sibling CSS, JavaScript, and image files together for basic relative references. Build-tool projects, module imports, fetches of local files, and nested folders need a real development server.

Game/WebGL compatibility: HTML previews support fullscreen, pointer lock, audio/autoplay, gamepad access, IndexedDB/local storage, downloads, and popups where the browser allows them. Because these permissions are needed for Unity/WebGL apps, only run HTML you trust.

Clearing site data clears saved files. Download important work. Received files are never executed automatically.
